# Bundled fonts

Fraunces and DM Sans are served by this app, without requests to an external font service. Both are licensed under the SIL Open Font License 1.1; their unmodified license texts are included alongside the fonts.

Original variable font files from the Google Fonts repository:

- Fraunces: https://github.com/google/fonts/tree/main/ofl/fraunces
- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans

`Fraunces.ttf` is the upright `Fraunces[SOFT,WONK,opsz,wght].ttf` file. `DMSans.ttf` is the upright `DMSans[opsz,wght].ttf` file. The files are renamed for simple URLs; their contents are unmodified.
